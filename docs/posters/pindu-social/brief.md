# 拼读社交分享海报

以个人英语素材为起点的设计方案，供讨论视觉效果。用于朋友圈、微博的单张图片分享，帮助第一次看到拼读的人了解产品，并前往仓库查看介绍与下载。

| 画幅 / 像素 | 3:4 竖版，1080 × 1440 |

## 构图与视觉

- 顶部保留真实品牌标识和产品类型；两行大标题形成第一阅读重点。

## 素材与制作

| 素材 | 来源 / 角色 |
| --- | --- |
| 软件首页 | `docs/screenshots/home.png`；真实产品截图；完整等比缩放，无界面重绘 |
| 品牌标识 | `public/logo-maskable.png`；原始品牌资产 |
| 纸张背景 | 内置 imagegen 新生成；气氛背景，无文字、标识或软件界面；实际提示词见 `background-prompt.txt` |
| 二维码 | 按行动目标生成；原图和缩略图分别解码验证 |
| 排版 | `poster.html`；可编辑的文案与布局；以浏览器实际渲染导出 |

`render.cjs` 使用已安装的 Playwright 与 Sharp，默认使用 Chrome。运行时可通过 `PROMO_NODE_MODULES` 指定这些库所在目录、`PROMO_BROWSER_CHANNEL` 指定浏览器渠道，输出目录可作为首个参数传入。背景与二维码的当前路径在 HTML 中登记；调整素材或批次时同步源文件。导出工具拒绝覆盖现有成图和布局记录。

背景、二维码、实际成图、检查与审图记录在当前批次中本地保存，不纳入 Git。跨机器续改需连同该批次拷贝。
