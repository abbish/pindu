# 产品宣传海报管理

每张海报保存当前设计说明、文案、素材来源与制作方式。与视频共用的规约见[宣传素材入口](../promo/README.md)，静态排版细则见[海报设计标准](../../.claude/skills/promo-poster-design/references/poster-design-standard.md)。目前没有已采用的具体海报。

## 保存方式

- 每个主题使用独立目录 `docs/posters/<poster>/`。同一海报修订原设计说明；同主题的多尺寸版本在说明里分别登记。
- `brief.md` 保存用途、观众、核心主张、精确文案、尺寸与观看场景、构图、风格、素材路径、制作方式、当前版本和修订记录。字段按实际需要使用，不为空项建立占位文件。
- 有可编辑排版源时保存实际 SVG、HTML 或制作脚本；使用 AI 图像时保存实际提示词、参考图角色与选定图像来源。源与提示词只在确实使用时建立。
- 成图、预览和检查记录保存在 `exports/<批次>/`，在工作区保存，默认不纳入 Git；更换电脑时需另行拷贝。项目代码正式消费的小型图像资产按项目原有资产方式管理。
- 新批次不覆盖已采用的图；设计内容变更更新版本与修订记录，审图后再登记采用的成图。当前设计、源与成图相互对应。
- 新增海报时在本索引登记名称、当前版本、尺寸和设计说明入口，并更新共同宣传素材索引。

## 生成与审图

`promo-poster-design` 承接规划和生成，用户只要方案时交付设计说明。生成时按画面需求使用当前环境可用的图像生成能力或已有可编辑源，不把真实产品截图改成虚构界面。

`promo-poster-review` 查看最终成图的完整尺寸及目标观看尺寸，核对文字、品牌、层级、截图、位置和行动区。有二维码时实际验证最终图，不用生成模型绘制二维码。

可用以下工具检查图片解码、尺寸、画幅与指定色彩模式，并生成观看尺寸预览。需要 Pillow（已有[视频工具依赖](../../scripts/video/requirements.txt)包含）：

```bash
python3 scripts/poster/check.py \
  --image docs/posters/<poster>/exports/<batch>/poster.png \
  --width <目标宽度> --height <目标高度> \
  --preview-width <预计观看宽度> \
  --output docs/posters/<poster>/exports/<batch>/verification.json
```

尺寸取当前设计说明；`--mode RGB` 等仅在明确要求色彩模式时指定。尺寸按 EXIF 旋转后的显示方向核对，记录中同时保留存储尺寸。预览保留透明度并等比缩小，不放大小图；实际预览尺寸写入记录。检查失败返回非零退出码；已有检查记录和预览不覆盖。工具不证明文字正确、布局美观、二维码可用或适合印刷。

在批次里保存简短 `review.md`：对应设计版本、实际查看尺寸与区域、发现和修正、链接/二维码验证范围、机械检查入口与未验证项。只写实际做过的核对。
