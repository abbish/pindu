# 宣传素材规约

本文面向宣传素材的策划、制作、审核与维护人员，是内部工作入口。对外海报、视频与产品介绍按目标观众需要呈现内容，制作流程与审核记录保留在内部资料中。

视频与海报共用产品事实、品牌、素材来源和功能口径，按各自媒介安排信息。核心价值与表达方向以[产品定位](../product/value-proposition.md)为准，当前功能与条件以[产品 README](../../README.md)为准；单次制作决定写入对应剧本或海报设计说明。

## 工作入口

| 请求 | Skill | 内容与产物入口 |
| --- | --- | --- |
| 宣传片策划、剧本、分镜 | `promo-video-script` | [视频剧本](../videos/README.md) |
| 按剧本生成或修改宣传片 | `promo-video-produce` | [视频制作与审片工具](../videos/tools.md) |
| 检查成片与优化质量 | `promo-video-review` | 视频当前剧本及实际导出 |
| 海报方案、文案、版式、生成或修改 | `promo-poster-design` | [海报管理](../posters/README.md) |
| 检查海报与优化质量 | `promo-poster-review` | 海报当前设计说明及实际导出 |

技能定位与自动选择条件见 [Skills 索引](../../.claude/skills/README.md#product-communication)。只要求规划时交付方案，已要求生成时继续制作；只 review 时交付问题，已授权优化时修正。

## 标准与单次决定

- [公共标准](../../.claude/skills/references/promo-standard.md)：品牌、产品承诺、素材、AI 生成与精确元素、跨媒介一致性、归档和授权边界。
- [视频质量标准](../../.claude/skills/promo-video-review/references/quality-standard.md)：画面、转场、标注、首帧、片尾、声音和编码证据。
- [海报设计标准](../../.claude/skills/promo-poster-design/references/poster-design-standard.md)：信息层级、构图、文字、观看尺寸、精确排版、多尺寸与导出。

时长、画幅、标题、卖点、链接、封面、片尾停留、具体配色等写入当前素材的说明，不抄进通用规则。同一批包含视频和海报时，共用已确认的核心主张和事实，文案按时序或静态画幅调整。
