# 拼读产品定位与价值主张

定位基线 1.0 · 2026-10-11。本文面向产品策划与内容维护人员，用于明确定位、分析价值与安排验证，是产品介绍和宣传主张的内部依据；具体功能和使用条件以[产品 README](../../README.md)及实现为准。

**拼读把自己身边的英语素材，变成每天能学、能练、能复习的学习资源。**

产品围绕学习者在学习、生活和工作中实际遇到的英语展开：把值得弄懂和记住的内容整理成词汇、短文与视频片段，接入练习和日常计划。内容与自己的需要有关，是定位的起点；把材料转成可执行的学习，是产品提供的服务；持续积累理解和使用这些英语的能力，是希望帮助用户取得的进步。

这里确立的是产品方向。个人相关的内容是否更能促成持续学习、练习是否能迁移到真实使用，需要通过用户行为和学习结果验证。

## 用价值主张画布建立定位

采用 [Strategyzer 的价值主张画布](https://www.strategyzer.com/library/the-value-proposition-canvas)：先明确一个用户群的任务、痛点与期望收益，再将产品能力对应到这些需要。用 [Jobs to Be Done（待完成任务）](https://www.christenseninstitute.org/theory/jobs-to-be-done/)补充具体情境与期望进步，避免用年龄或功能偏好代替需求。以下是对拼读的应用；用户侧分析是待验证假设，功能侧依据现有产品。

### 优先服务的用户与任务

优先用户是：**在学习、生活或工作中持续接触英语，手边已有想弄懂的内容，并愿意围绕它开展日常学习的人。** 首轮验证可先聚焦经常阅读英文资料的桌面用户，例如使用英文专业资料、项目文档或课程材料的人。其他内容场景后续分别验证，不把所有英语学习者视为同一群体。

用户任务可以表述为：

> 当我在学习、生活或工作中遇到一段值得弄懂、记住的英语时，我想把它整理成能反复学习和练习的内容，以便下次遇到类似内容时，更容易看懂、听懂或用上。

任务同时包含理解当前材料与积累后续能力。情绪上的期望可能是“知道自己为什么学这些内容”“能看见与自己有关的积累”；这些期望也要在访谈中核实。

### 用户需要与产品提供的价值

| 画布要素 | 对拼读的定义 | 当前依据 / 验证重点 |
| --- | --- | --- |
| 用户任务 | 弄懂实际遇到的英语，并把其中值得学的部分持续练习 | 验证用户过去如何处理一份真实材料，何时需要再次使用 |
| 痛点 | 查词或翻译后就结束；材料收藏后未再学习；整理词汇、练习和复习安排费力 | 属于需求假设；观察真实处理过程与放弃点 |
| 期望收益 | 内容与自己的目标有关；每天知道学什么；再次遇到时能回忆和理解 | 相关性、持续性和实际掌握分别验证，不能只询问“是否喜欢” |
| 产品与服务 | 词汇整理、英文材料导入、视频片段学习、练习与学习计划 | 当前 README 的词汇本、短文、视频库、计划与练习章节 |
| 减轻痛点 | 从材料提取重点词，补充学习资料，提供练习，将内容接入计划 | 各项能力已存在；完整流程的操作负担与耗时仍需观察 |
| 创造收益 | 在自己的内容和语境中学词句，以每日任务与复习延续学习 | 功能能够支持这种路径；持续使用和真实场景效果尚未验证 |

## 产品定位与差异

**产品类别：围绕个人英语素材的日常学习工具。** 提供 macOS 和 Windows 桌面应用。

完整定位句：面向日常已有英语接触、希望围绕真实需要学习的人，拼读将他们身边的文本、文档和带字幕的视频整理成学习与练习资源，并通过计划和复习帮助持续学习。

差异在于学习的起点和组织方式：预置课程或资源库通常从产品提供的内容开始；拼读以学习者实际遇到、愿意弄懂的内容为主线，再为这些内容配上学习结构。这是选择服务哪类需要，不是判断哪种方式普遍更有效。

| 用户当前采用的做法 | 已解决的问题 | 拼读希望承接的下一步 |
| --- | --- | --- |
| 选预置课程或资源库 | 有现成内容与学习路径 | 围绕自己近期真正遇到的内容组织学习 |
| 查词、翻译 | 快速理解眼前内容 | 把需要记住的词句继续练习和复习 |
| 收藏文章、视频或笔记 | 保存材料，方便以后找回 | 将收藏转成可执行的学习任务 |
| 手工整理词卡和练习 | 能定制自己的学习内容 | 减少从材料到词汇、语境练习和计划之间的整理负担 |

该表比较的是使用方式，未进行具体竞品审计。许多产品可能也支持自定义材料；“唯一支持个人素材”“其他产品都只有预置资源”不作为宣传结论。拼读要持续建立的差异，是自己的材料在完整学习过程中处于什么位置，以及这条路径是否方便、有效。

## 四项产品特点及其证据

| 特点 | 对用户的意义 | 当前产品支持 |
| --- | --- | --- |
| 从自己的材料开始 | 知道所学内容与自己有什么关系 | 从文本、字幕和文档提取词汇；导入英文材料；导入本地视频与字幕 |
| 把材料转成学练资源 | 减少自己准备学习资料的负担 | 词汇资料、逐句译文、重点词、句子讲解、题组与视频片段整理 |
| 带着语境练习 | 将词句与实际出现的内容联系起来 | 短文阅读与听力、词卡与句子分析；视频台词、跟读录音与听句拼写 |
| 每天继续学和复习 | 当天有可执行的任务，已学词汇能再次出现 | 学习计划、每日任务、词汇分级复习；短文和视频片段可以加入计划 |

自然拼读、讲解、素材生成、本地保存和无需账号是支撑能力或使用特点。AI 承担部分整理、补充和讲解工作，通用产品介绍优先表达用户获得的价值。按主题或词汇生成补充材料可以服务用户的目标，不要求所有资源都来自导入。

使用边界需准确：目前通过用户提供文本、受支持的文档文件、本地视频与字幕导入；不承诺任意网页链接自动采集、扫描件识别或没有字幕也能直接完成视频学习。资料保存在本机；使用 AI 或语音时，相关内容会发送到用户配置的服务商，具体条件见 README 的安装与隐私章节。

## 用这个定位决定产品优先级

新增功能首先回答：它能否帮助用户把真实材料更顺畅地变成可持续的学习？优先考虑导入与选择内容、学习重点整理、材料与练习衔接、每日继续学习，以及回到原文或原片段查看词句。

素材相关性也需要设计。自己的材料可能过长、过难或重点不清；帮助选择适合当前目标的部分，比把整份资料一次性变成大量任务更符合这条主张。内容生成与讲解应围绕用户需要提供补充，学习计划应让任务量可控制。

当前产品已有上述能力的组成部分。跨入口衔接、来源呈现和首次使用是否足够顺畅，仍需实测；本文不将愿景描述成已经完成的一键流程。

## 验证相关性、转化和持续学习

先邀请 5–8 位同一优先用户群的参与者，带来过去一周真正想弄懂的英语材料，进行一周的小范围观察。人数与周期是建议的首轮试验安排，不是已执行的研究。依据 Strategyzer 的[价值主张测试建议](https://www.strategyzer.com/library/ways-to-test-your-value-proposition-and-business-model)，关注过去的真实经历和实际行为，减少“你会不会用”式询问。

| 要验证的假设 | 观察方式 | 结果如何影响决定 |
| --- | --- | --- |
| 手边已有材料，且相关性足以驱动学习 | 让参与者带来近期真实材料，说明当时的任务、处理方法及再次使用的需要 | 找不到材料或没有学习动机时，重新收窄用户群和情境 |
| 从材料到第一次练习的负担可接受 | 观察独立完成流程的时间、步骤、卡点与放弃原因；分别看文本和视频 | 不能顺畅完成时先改善关键路径，再增加来源类型 |
| 用户愿意回来学自己的内容 | 观察一周内是否再次学习与复习同一来源内容，是否继续添加材料 | 只导入而不再学时，检查任务量、入口和练习价值 |
| 学练有助于再次理解或使用 | 在后续回访中用原材料及类似但未练过的内容，检查理解、回忆或表达，并询问真实使用经历 | 区分熟悉原文、迁移能力和主观感受；短期小样本不作普遍效果承诺 |

优先关注完整路径：**自己的材料 → 第一次学习/练习 → 后续复习 → 再次理解或使用**。导入数量、生成数量、打开次数只能说明部分活动。研究采用自愿参与的观察与访谈，本文不要求在应用内新增遥测。

## 产品介绍与海报表达

- **核心价值主张**：把自己身边的英语素材，变成每天能学、能练、能复习的学习资源。
- **海报标题**：把身边的英语素材，变成每天的学习。
- **支持文案**：从学习、生活、工作中遇到的内容开始。
- **三项传播重点**：用自己的素材 / 变成学练资源 / 每天继续学习。
- **介绍短文**：拼读是一款围绕个人英语素材的日常学习工具。把学习、生活和工作中遇到的文本、文档与视频字幕整理成词汇、短文和视频片段，配合练习、学习计划与复习，每天继续学习与自己有关的英语。

主张先讲内容与用户的关系，再讲如何转成学练资源，最后用现有功能作证。海报、首页介绍和宣传片沿用这个顺序；技术条件在相应使用说明中准确交代。宣传素材版本在[共同入口](../promo/README.md)登记。
