# 拼读 v0.4.0

### 发音

- 单词练习可以跟读：读完马上知道读得怎样、哪个音不准，读过关自动进入拼写。
- 短文和场景片段可以逐句跟读，读得不准的词会标出来，还能听自己的录音。
- 可以说话代替打字：对 AI 老师说中文、英文都行，开放题可以用英语说出来。
- 评分和识别都在你的电脑上进行，录音不上传；学习计划能看到常读不准的音。

### 视频与场景片段

- 没有字幕的视频也能导入：在你的电脑上识别英文语音生成字幕；视频旁边和视频自带的字幕会自动找到。
- 场景片段分为观看、跟读、听力三种，原文朗读和听力题默认用视频原声，也可换成 AI 朗读。
- 切分视频时一并生成单词卡，学的时候打开就能看。

### 设备互传

- 同一网络中的电脑核对 6 位数字即可配对，词汇本、短文、视频、场景片段和学习计划都能发送到另一台电脑。
- 学习计划可以连同学习进度一起发送，换一台电脑接着学。

### AI 老师

- 可以搜索对话，从自己说过的某句话「重新问」，另开一个对话。
- 对话很多时打开更快，⌘N / Ctrl+N 开新对话。

### 学习计划与短文

- 计划卡按周期显示第几天，进度分已学和已掌握两段；统计分成拼写、发音、阅读和听力。
- 首页显示已学单词、已掌握单词、一次答对率和连续学习；短文答题也计入学习时长和连续学习。
- 朗读工具栏常用开关直接可点，往下读时固定在顶部；每句后面都能直接跟读。

### 其他

- 设置重新分组为学习偏好、服务与模型、数据与设备、通用；音标默认改为美式。
- 只支持 macOS 与 Windows，不再提供 Linux 版本；跟读和说话输入需要 macOS 14 以上（Apple 芯片）或 13.4 以上（Intel 芯片）。
- 多处问题修复。
