拼读的第一个正式版本。

**能做什么**

- 建单词本：手动录入、让 AI 按描述生成，或从自己的材料（txt / md / srt / vtt / docx / pdf）里挑出生词；每个词自动补上音标、音节、拼读拆分和例句。
- 按计划学：选好单词本和每天的新词数，日程自动排好；新词分三步练，复习按记忆等级（1 / 3 / 7 / 14 / 30 天）每天自动安排。
- AI 讲解：记不住的词点开讲解，看拼写规律、同规律的词和记忆办法，还能接着问 AI 老师。
- 短文：用学过的词让 AI 写短文，或者导入自己的英文材料，逐句朗读、听力练习、阅读理解题自动判分。

**安装**

下载对应系统的安装包：macOS 用 `Pindu_0.1.0_universal.dmg`，Windows 用 `Pindu_0.1.0_x64-setup.exe`，Linux 用 AppImage、deb 或 rpm。应用没有做苹果和微软的开发者签名，第一次打开时系统会拦一下，放行方法见 [INSTALL.md](https://github.com/abbish/pindu/blob/main/INSTALL.md#1-下载安装包)。

装好后到「设置 → AI 模型」填上自己的 API Key（支持 OpenAI 兼容接口，内置 OpenRouter、MiniMax、月之暗面、DeepSeek），发音需要火山引擎豆包语音合成。

从这个版本起，有新版本时应用里会提示，点一下就能更新；每次升级前会自动备份数据。
