# 拼读 v0.3.0

### AI 老师

- 新增独立的 AI 老师对话：查词、翻译、讲句子和语法，支持截图、PDF、Word 和图片，对话自动保存。
- 能结合你的词汇本和学习情况回答，也能直接帮你建词汇本、写短文、出题、安排学习计划。
- 处理过程逐步可见；删除、结束计划等改动前先征得你同意，权限可在设置中调整。
- 可以设定老师的名字、说话风格和性格。

### 素材

- 短文可以直接从 PDF、Word 和图片导入，沿用材料里的翻译和词汇表。
- 单词海报、词汇表图片和 PDF 可以直接整理进词汇本。
- 阅读理解与听力练习分开出题，听力题按「只听不看原文」来出。
- 可以重新挑选短文的词汇，编辑短文与场景片段的标题、难度和标签。
- 视频切出的学习素材改称「场景片段」。

### 学习计划

- 新建计划改为一页完成，学习顺序可选「从易到难」或「按词汇本顺序」。
- 计划详情最上面直接显示今天要学什么。

### 其他

- 后台任务显示在所属的模块旁边，并新增「后台任务」页面。
- 设置重新分组为「学习者」「AI 任务」「AI 老师」，模型列表标出能看图片、深度思考等能力。
- 服务商繁忙时自动重试，停止生成后不再保存半成品，以及多处问题修复。
