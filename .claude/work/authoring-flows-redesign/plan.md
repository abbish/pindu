### B. 流程设计问题（改版解决）
- 单词本创建是“向导里套向导”：3 步页面里弹出 5 步导入弹窗，**选两次词**；弹窗按钮叫“保存单词”实际不保存。
- 创建与补充单词是两套映射代码、两种空值写法；创建与编辑单词本两套表单（主题必选 vs 可空、描述长度、按 name vs id 选主题、图标创建时不能选）。
- 草稿语义含糊：单词本草稿只能在最后一步保存、唯一作用是“不能用于计划”且只在前端过滤；计划草稿是“编辑态”，编辑 → 草稿 → 发布 两次往返，改个名字也要暂停计划。
- 计划“开始日期”实际不生效（第一次练习一律平移到当天），表单与预估却当真。
- AI 只负责单词排序，却卡在创建关键路径上：没配模型就无法创建，要等 1–3 分钟，失败无兜底（`normalize_order` 本可按长度估难度兜底）。
- 计划向导第 2、3 步内容重复；创建与编辑表单不一致（预估、校验时机、文案）。
- 手动添加单个单词**没有入口**（`add_word_to_book` 无调用方）。
- 确认强度倒挂：删单词本（软删、可恢复）要输入名称；删单词（不可恢复、级联删练习与记忆）只有普通确认。
- 没有模型时导入是死路（按钮禁用无引导）；删到最后一页后空页死路；恢复单词本成功 / 失败都无反馈；后端拒绝原因（如“被计划使用”）被通用 toast 吞掉。

### C. 遗留与死代码
计划请求仍带 intensityLevel / studyPeriodDays / reviewFrequency / aiPlanData 字符串（创建）与 schedule 对象（编辑）两种形状；编辑传的 wordbookIds 后端忽略；无调用方命令 create_study_plan / update_study_plan / create_word_book / add_word_to_book；批量分析的 retry_failed_words 等参数从未读取；事件推送前端未监听；`updateAllWordBookCounts` 冗余；进度卡“关闭”按钮永不出现、字符数恒 0。

## 2. 设计原则（来源：shadcn Examples / 桌面应用惯例，见 ui-interaction-patterns.md）
1. **先建对象，再填内容**（Anki 牌组 / Notion 页面 / Things 项目的通用模式）：创建只收最少信息，内容在详情页里加。
2. **一个任务一个界面**：同一件事只有一个入口和一套组件（“添加单词”在新建与补充时完全相同）。
3. **AI 是增强，不是关卡**：确定性部分（日程、预估）即时可见；AI 部分可选、可取消、失败有兜底。
4. **长任务不丢结果**：分析结果在保存成功前一直保留；取消 = 保留已完成的部分并明确告知。
5. **破坏性操作按后果分级确认**，可撤销的操作用 toast“撤销”而不是重确认。
6. **编辑就地生效**，不需要“转草稿 → 发布”的状态往返。

## 3. 目标流程

### 3.1 单词本
- **新建**：列表页 / 首页“新建单词本” → Dialog（名称、图标与颜色、主题、描述；共享 `WordBookForm`，与编辑同一组件同一套校验）→ 创建空单词本 → 进入详情页。
- **详情页空状态**：主操作“从文本添加单词（AI）”，次操作“手动添加单词”。
- **添加单词**（新建与补充共用，大尺寸 Sheet 或整页，单一步骤条，不再嵌套确认页）：
  1. 输入：粘贴文本 / 选文件；提取范围（重点词 / 全部）；模型（没有可用模型时显示“去设置 AI 模型”而不是禁用按钮）。
  2. 选词：网格勾选；**已在单词本中的词标“已存在”且默认不勾**，勾选时提示“将用新分析覆盖”。
  3. 分析：逐词状态与进度；“停止分析”= 停止剩余批次并保留已完成的词，明确提示“已完成 N 个，未分析 M 个”；失败词可单独重试。
  4. 检查并保存：结果列表（可去掉个别词）→ “保存 N 个单词”。保存失败结果保留，可重试。
  - 结果在保存成功前一直保留；关闭时若有未保存结果，AlertDialog 确认“放弃分析结果？”。
- **手动添加 / 编辑单词**：同一表单（创建模式调 add_word_to_book）；拼读块用可编辑的分段标签，改音节可一键按音节重切；词性下拉补全；例句按行编辑（英文 + 中文两个输入）。
- **删除单词**：批量删除走后端单事务命令；确认框列出影响（“其中 3 个正在学习计划中，删除后学习记录与记忆进度一并删除”）；勾选范围明确为“本页 / 全部筛选结果”。
- **删除单词本**：软删除 → 普通 AlertDialog（被计划使用时直接说明不能删及计划名）→ 成功 toast 带“撤销”（调用 restore）。“已删除”筛选里可恢复，恢复有反馈。
- **草稿**：单词本不再有“草稿”概念（空单词本自然不能用于计划，后端加校验）。存量 draft 怎么处理见待决策 1。

### 3.2 学习计划
- **新建**：单页表单（替代三步向导），左表单右预览（同计划详情页尺寸）：
  - 单词本（多选，显示词数；没有单词本时引导去新建）
  - 节奏：每天新词数（分段选择 + 自定义 1–50）
  - 学习顺序：「AI 智能排序」开关（按难度与关联排序，需要模型，约 1–3 分钟）/ 关闭时按词长与原顺序排
  - 名称、描述（名称默认按单词本生成，可改）
  - 右侧**即时预览**（确定性计算，无需 AI）：共 N 个新词、学新词 X 天 + 巩固 11 天、每天安排的前几天示例
  - 主操作“创建计划”：AI 排序开启时在原地显示进度（可取消；取消或失败可选“改用默认顺序创建”）
  - 创建后状态为“待开始”，**第一次练习即开始，日程从那天起算**（去掉不生效的“开始日期”）
- **编辑**（计划详情页“设置”页签，复用 SettingsLayout 的设置行，就地生效，不再转草稿）：
  - 名称、描述：任何状态可改，失焦或回车保存
  - 每天新词数：未开始的计划直接重排；已开始的计划只重排**尚未学过的新词**，已学数据与记忆等级不动（显示影响：“剩余 X 个新词，将在 Y 天内学完”）
  - 单词本：添加单词本 → 新词追加到后续日程；移除单词沿用现有“从计划移除”
  - 危险区：重新开始（清空进度，现有 restart）、删除
- 状态：用户可见状态收敛为 待开始 / 进行中 / 已暂停 / 已完成 / 已终止；Draft 只保留给后端兼容，不再出现在 UI。
