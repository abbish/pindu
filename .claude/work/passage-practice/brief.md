# 工作简述

- 用户目标：在单词练习之外，增加和这些单词配套的「短文练习」（阅读 + 听力），像考试的阅读理解 / 完形填空：用学过的词写短文，配题目，客观题代码判分、开放题 AI 评分。和单词练习组成同一套练习。
- 成功标准：
  1. 单词本里可以随时「用这些词生成短文」做自由练习；
  2. 学习计划可开启短文练习，按频率（每天 / 每 2 天 / 每 3 天）在当天任务里出现一篇，内容用这个计划里学过 / 正在复习的词；
  3. 阅读模式：选词填空 + 阅读选择 + 判断正误（代码判分）+ 开放题（AI 评分与评语）；听力模式：用豆包 TTS 逐句朗读，先听后看原文答题；
  4. 短文练习单独统计（正确率、开放题得分、用时），不影响单词记忆等级与单词统计。
- 范围（触达的层）：迁移 053+、repository / service / handler / lib.rs、types（rs/ts）、agent 任务（提示词 + submit 工具 + 评测）、前端新页面与入口（单词本详情、计划详情、首页今日任务、新建计划 / 计划设置）。
- 非目标：跟读录音、发音评测（依赖新的外部 API，暂缓）；短文结果参与 SRS；日历 / 连续天数口径变化；手工编辑短文与题目。
- 关键约束：迁移只增不改；新 LLM 能力做成 agent 任务、结构化结果经 submit 工具并由 Rust 二次校验；不新增第三个进度管理器；新建计划页 / 计划设置页 / 计划统计页是协作会话（redlark-3b）近期改过的文件，动之前先协调。
- 已确认事实：TTS `text_to_speech(text, voiceId, useCache, style)`，单次 ≤1000 字符，`style=sentence` 有句子语音指令并参与缓存键；单词本场景（D22）与学习者档案（D21）已可注入提示词；计划日程表 `study_plan_schedules` 一天一行（plan_id+schedule_date 唯一）；SRS 等级在 `study_plan_words.srs_box/srs_due`。
- 推断 / 未知项：短文生成耗时（预计 20–60s，需真实模型测量）；不同模型对“只用学过的词”的服从度（靠评测）。
- 用户决定（2026-10-07）：
  - 定位：不是独立模块，是练习类型；内容挂单词本，计划负责安排；可从单词本自由练习。
  - 跟读与口语评测暂缓。
  - 听力第一期做（复用已有 TTS）。
  - 短文练习单独统计；完形填空不用于考核单词记忆，不影响记忆等级。
- 用户决定（2026-10-07 调整，取代上面的“内容挂单词本”）：
  - **短文是独立素材**（与单词本并列，侧边栏分组「素材库」= 单词本 + 短文；一级菜单只留 首页 / 学习计划 / 日历）。
  - 短文的词汇与场景来源可组合：多个单词本、学习计划（难词 / 已学 / 今日到期复习）、手动输入的词；短文记录来源，删除来源不删短文。
  - 学习计划的练习内容两套、互相独立：单词练习（单词本）与短文练习（短文）；计划可只练单词、只练短文或两者都练；只练短文不需要单词本。
  - 计划里的短文**从短文库选**，计划本身不产生素材；“从计划提炼难点生成新素材”是以后的增强功能。
  - 难词 = 计划中已学（记忆等级 ≥1）且（记忆等级 ≤2，或首次作答答错 ≥2 次）。
