# 学习计划改造：每天新词数 + 自适应间隔复习（Leitner）

用户（2026-10-07）：面向儿童与成人，按成熟、科学的方法改造计划参数与排程。

## 方法依据
- 间隔重复（spacing effect）+ 检索练习（testing effect）：复习 = 不看答案回忆拼写（盖-写-查），不是重新学。
- 自适应间隔：Leitner 盒子（与 Anki / SM-2 同类思路的简化版）：答对升级、间隔拉长；答错回到 1 级。
- 间隔以**实际练习日期**为基准（漏练不打乱）；每日复习有上限，避免积压一次压垮。
- 掌握 = 间隔 ≥7 天后仍能首次写对（升到第 4 级），而不是当天三步全对。

## 规则（唯一 owner：`services/srs.rs`）
- 盒子间隔（天）：1→1、2→3、3→7、4→14、5→30；box 0 = 未学。
- 新学当天练完：box=1，due=练习日+1（不论对错；当天的纠正与重考已处理错词）。
- 复习（只做第三步：听音 + 中文，独立拼写）首次作答：对 → box+1（最多 5），due=今天+间隔；错 → box=1，due=明天，lapses+1。
- 掌握：box ≥ 4。
- 每日复习上限：clamp(每天新词数 × 3, 15, 60)，优先最早到期、等级低的。

## 参数
- 用户选：每天新词数（3/5/8/10/15/20/30，默认 10）+ 开始日期。
- 系统算：学新词天数 L = ceil(词数/每天新词数)；周期 = L + 11（最后一批词走完 1→3→7 天三次复习达到掌握所需天数）。
- intensity_level / review_frequency 保留列作兼容：intensity 按每天新词数映射（≤5 easy，≤12 normal，其余 intensive），review_frequency 存 0。

## 日程
- 预先生成的日程只有新词日（第 1..L 天）。
- 复习动态生成：`sync_today(plan)` 把今天到期的词放进**今天**的日程行（没有就创建），清理过去 / 未来未练习的复习条目；今天已有进行中会话时不改。
- 调用点：开始练习、今日日程、日历月视图、计划日程列表。
- 计划自动完成：所有新词日已练完且所有词 box ≥ 4。
