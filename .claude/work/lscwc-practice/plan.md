# plan

## 三步与五个环节的对应
| 步骤 | 环节 | 提示 | 时机 |
|---|---|---|---|
| 第一步 看·说 → 盖·写 | 看（全部信息，难点高亮）→ 说（发音时拼读块逐块亮起、跟读）→ 盖 → 写 | 字母格 + 音标 + 音节 / 拼读块结构 | 学完立刻 |
| 第二步 盖·写 | 盖 → 写 | 字母格 + 音标 | 同组其他词练完后（交错） |
| 第三步 听写 | 盖 → 写 | 只有发音与中文 | 同组第二步全部完成后 |
| 当轮小测 | 听写 | 只有发音与中文 | 本轮所有组结束后 |
| 每次作答 | 查 | 逐字母比对、错误对应到拼读块 → 照正确拼写重打 → 稍后重考（每步最多 2 次） | — |

## 批次
1. 练习引擎 + 查 + 交错（前端）：`utils/practiceQueue.ts`（分组 5 词、按步交错、错题插回、当轮小测、断点恢复）、`utils/spellingCheck.ts`（逐字母对齐、错误对应拼读块）、练习页改为按任务队列推进、答错进入纠正模式、第一步看·说→盖·写。
2. 复习日只做“盖-写-查”：区分新学 / 复习练习模式（复习日跳过第一步，错了才回到看·说）。
3. 按表现安排复习：每词掌握度（迁移），复习间隔随一次答对 / 重试次数调整，替代固定 1/2/4/7/15。
4. 统计与薄弱点：一次答对率、隔天保持率、最常错的拼读块。
