# brief：练习模块逻辑与统计审计修复

目标：练习相关的流程与所有统计数字（结果页、首页、计划详情、日历、练习统计）正确且口径一致。
来源：用户要求“以练习这个大的功能模块为范围，进行分析优化”（2026-10-07）；前后端两路只读审计（约 30 条，见 analysis.md）。

统一口径（本次确立）：
- 首答正确率：只看每个（会话, 单词, 步骤）第一条 kind = learn 记录。
- 单词“学会 / 完成”：与日程完成相同——某已完成会话中三步首答全对（refresh_completion）。
- 时长：active_time（不含暂停）；会话中途持续落库，恢复后接着累计。
- 日期：一律按本地日期（SQLite `DATE(x, 'localtime')`，前端本地日期）；日历按日程日期判断完成。
