# 时间与时区统一约定

## 目标（用户，2026-10-07）
数据存储默认一律 UTC；使用时按客户端时区正确展示。“这块非常重要”。

## 范围
后端存储格式与默认值、Rust 取时、SQL 时间运算、IPC 时间字段、前端解析 / 计算“今天” / 展示、检查与测试。

## 成功标准
- 每个时间值都能归入两类之一并按规则处理：**时刻**（UTC，唯一格式）/ **日历日期**（本地日，不做时区换算）
- 库内时刻只有一种格式；新写入由代码显式产生，有不变量测试与检查脚本兜底
- 前端只经一个工具模块解析与格式化时间；单词本详情等处不再显示错日；跨零点后“今天”自动更新
- 规则写入 CLAUDE.md 硬性规范 + 一份 contract reference，可机械判定的部分由脚本 / lint 守住

## 约束
- 迁移只增不改；不做表重建（外键级联风险见 CLAUDE.md §8）
- 后端由另一会话并行开发：后端批次开工前与其对齐分工
- 历史数据不删除，只做格式归一（确定性的字符串转换）
