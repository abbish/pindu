# Promo Poster Design

产品传播工作流的海报入口。把传播目标、产品证据、文案与构图形成设计说明，并在用户要求生成时交付实际海报。单页海报的策划与制作共用此入口。

## 按需读取

- 每次策划或制作：读 `../references/promo-standard.md` 与 `references/poster-design-standard.md`。
- 归档或续改：读 `docs/posters/README.md`、对应 `brief.md` 与已采用的海报；同批有视频时读其当前剧本，核对共同主张与行动目标。
- 核对产品卖点、标识与颜色：沿公共标准读实际产品文档与品牌资产。
- 需要 AI 位图生成或编辑时，遵循当前环境的 imagegen 技能/工具流程；不复制某台机器的技能路径或固定 API 型号。

## 输入

产品、传播场景、观众、核心主张、目标尺寸/观看尺寸、现有素材和本次修改。需求不完整时先做可调整方案；生成阶段影响构图的用途或比例无法推断时才提问。

## 负责 / 不负责

- 负责海报文案、信息层级、构图、风格、素材、精确元素排版、实际导出与设计说明。
- 不把用户要求的 AI 插画替换成代码占位图，不重绘真实产品界面，不擅自修改品牌或发布海报。

## 规则

- “先规划 / 先设计方案”只交付目标、文案、构图与素材安排；“生成一版”才制作实际图片。已有生成授权内的修改不重复确认。
- 主标题表达一个清楚的价值；支持信息证明它，行动提示指向用户当前指定的目标。采用多少卖点取决于内容和尺寸，不照搬视频全部台词。
- 图像型背景或插画用可用图像生成工具；已有 SVG、HTML/CSS 或可编辑排版源中的布局修改沿用原生源。真实截图、品牌标识和精确文字保持可核对。
- 原生源保留文字与图层；AI 图像流程保存实际提示词、参考素材角色及最终选择。中文、链接或品牌字形错误要修正后交付，不能以“模型生成”解释为已完成。
- 编辑已有 PNG/JPEG 等图像时按可用图像编辑工具处理；已有可编辑的 SVG 或 HTML/CSS 排版源沿原源修改。检查用的缩略预览不代替交付成图。
- 多尺寸改版重新排布标题、截图与行动区，不拉伸、裁断或直接缩小整张海报。只处理用户请求的尺寸或版本。
- 生成后进入 `../promo-poster-review/SKILL.md` 检查实际文件，记录版本与导出批次。

## 默认执行方式

1. 恢复现有决定，整理一个核心主张、精确文案与证据素材，确定媒介约束。
2. 写构图与视觉方向；仅规划时在此交付。
3. 用户已要求生成时选择适合的制作方式，生成或调整视觉，完成精确排版和实际导出。
4. 在目标观看尺寸审图，修正授权范围内的问题，归档并交付。

## 输出形态

方案：主张、标题/支持信息/行动文案、构图、尺寸、风格、素材与待确定项。

成图：实际海报预览及文件、设计说明、可编辑源或提示词、版本与审查结果。

## 完成条件

请求停在对应阶段；卖点与素材有依据；生成请求有实际导出图片；精确文案与产品画面正确；布局适合目标观看尺寸；来源和版本可恢复。
