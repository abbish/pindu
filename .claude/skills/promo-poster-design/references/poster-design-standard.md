# 宣传海报设计标准

产品事实、品牌、素材与生成边界以[公共标准](../../references/promo-standard.md)为准。本标准负责静态海报的构图和交付。

## 信息层级

- 默认建立品牌识别 → 一个核心标题 → 产品证据 → 必要支持信息 → 行动区的阅读顺序，允许随内容调整。每一块承担清楚的作用。
- 主标题宜短，优先一至两行；支持信息只保留帮助理解主张的内容。卖点较多时选重点或拆成用户要求的一组海报，不能塞成缩小字号的功能清单。
- 标题、截图、标签和行动提示分别明确主次。不要仅靠“特色”“强大”“智能”等形容词代替产品证据。
- 综合产品介绍可承接同批视频的素材类型、学练方式与 AI 价值；单功能海报聚焦该功能，不强制重复全部产品能力。

## 构图与文字

- 依据发布位置、画幅与观看尺寸选择主视觉。截图展示全景还是细节由主张决定；要看清按钮或台词时选择细节裁切。
- 先建立内容区、对齐线和留白；安全边距可从短边的 4–6% 起步，按平台遮挡、内容密度和画面调整，不作为所有海报的硬尺寸。
- 保持截图比例；避免主标题和产品截图互相争夺空间。装饰背景不穿过小字、关键按钮或下载信息。
- 用中文完整词组安排换行，检查中英文混排、标点、孤字、基线、截断和溢出。精确文案、品牌名、URL 不依靠未经核对的生成文字。
- 在实际预计观看宽度查看。原图看着清晰、缩到社交信息流却读不清时，应减少信息或改变布局，而非仅扩大输出像素。

## 素材与技术路线

- 真实软件展示默认采用授权产品截图；需要气氛或插画时可生成背景，再保留可核对的产品截图与文字。明确用户请求的整图生成或图像编辑按可用图像工具执行。
- 现有 logo 与品牌字形作为原始资产或已采用的品牌组件复用，不让生成模型重新绘制。
- 创作背景时说明用途、主题、风格、构图、文案留白和限制；参考图标明是风格参考、必须保留的产品内容或编辑目标。
- 二维码由正确地址编码，不生成貌似二维码的装饰。导出后在最终图和目标观看尺寸实际核对；不能验证时明确说明并考虑采用可读短链接。

## 版本与输出

- 不从聊天中临时猜平台规格。指定平台且规格影响交付时核对其官方要求；用户已给尺寸则以该尺寸为准。
- 横版、竖版、方版分别重排；只输出用户需要的版本。屏幕素材通常导出 RGB PNG，需照片压缩时可选高质量 JPEG；透明度、打印色彩、出血或 PDF 仅按实际用途处理。
- 当前版记录目标像素尺寸、画幅、观看场景、文案和源素材。保存可编辑源；图像生成流程保存实际提示词与选定图像。
- 检查最终导出文件及目标观看尺寸，记录文字准确性、层级、截图定位、链接与二维码验证范围。机械尺寸检查不证明设计质量。
