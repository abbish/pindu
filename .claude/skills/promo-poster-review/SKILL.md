# Promo Poster Review

产品传播工作流的海报质量入口。检查实际成图及观看尺寸，区分机械参数、视觉核对、文案与二维码验证，按用户授权报告或修正。

## 按需读取

- 审图：读 `../references/promo-standard.md`、`../promo-poster-design/references/poster-design-standard.md`、当前设计说明及对应导出。
- 检查导出参数：读 `docs/posters/README.md`，使用 `scripts/poster/check.py`。
- 同批含视频：读视频当前剧本或已采用的成片文案，核对品牌、主张、功能口径与行动目标。
- 用户已授权修正：进入 `../promo-poster-design/SKILL.md`。

## 输入

实际 PNG/JPEG 等成图、当前设计说明、尺寸与观看场景、源素材和本次修改。仅有设计稿时报告设计稿审查，不宣称成图检查通过。

## 负责 / 不负责

- 负责文案、品牌、信息层级、截图真实性、布局、观看尺寸、链接/二维码与实际导出质量。
- 只 review 时交付 findings；已授权优化时修正范围内的问题，不重新策划用户已接受的方向。
- 不擅自上传、发布或生成额外版本。

## 规则

- 查看实际导出图的完整尺寸与目标观看尺寸；小预览不能证明小字和截图清晰。
- 对照设计说明逐字核对标题、卖点、品牌名、URL 与署名。生成图像中的中文、按钮与 logo 尤其要查。
- 核对截图/标注与原始素材；没有实际验证就不能确认二维码可用。跨媒介一致性按同批素材检查，不把单片偏好当作通用要求。
- 机械检查只证明图片可解码、尺寸、画幅、格式和色彩模式等；视觉、语义、印刷适配分别记录，不自动填写通过。
- 局部修改复查受影响区域及整体信息层级；无新增风险时不反复重做整张图。

## 默认执行方式

1. 对账设计版本与导出，确认本次保护的要求。
2. 检查图片参数，在两种观看尺寸核对文字、素材、位置、层级与行动区。
3. 报告位置、问题、影响和证据；已授权时修正再导出复查。
4. 保存检查结果与明确的未验证项，交付实际文件。

## 输出形态

发现或修正结果，附区域与证据；检查过的尺寸和项目、未验证项；海报、源文件与检查记录链接。

## 完成条件

实际成图可解码并符合目标尺寸；主要文字、截图与行动区有视觉核对结果；影响交付的问题已修正或明确报告；没有以机器参数代替实际审图。
