# 拼读（Pindu.app）

[English](./README.en.md) · [安装](./INSTALL.md) · [安全与隐私](./SECURITY.md)

**把自己身边的英语素材，变成每天能学、能练、能复习的学习资源。**

拼读是一款桌面英语学习工具，支持将文本、文档、本地视频与字幕整理成学习材料，配合词汇、阅读、听力、拼写、跟读与复习。

支持 macOS、Windows 和 Linux，无需注册账号。使用成本见[费用说明](#使用费用)，安装与服务配置见[安装说明](./INSTALL.md)。

首页汇总每日任务、学习计划与学习进度，支持继续未完成的练习。

![首页](docs/screenshots/home.png)

## 功能

### 词汇与自然拼读

管理单词与词组，支持从文本、文档和图片提取词汇，或按学习需求生成。单词卡提供音标、音节、自然拼读、释义和分级例句。

![词汇本与单词卡](docs/screenshots/wordbook.png)

### 文档导入与阅读

导入文本、PDF、Word 或图片，保留原文和已有译文，补充逐句翻译与重点词汇。导入前可预览和编辑。

![文档导入](docs/screenshots/import.png)

阅读页支持逐句朗读、重点词汇查看和选词收录。也可围绕词汇或主题生成练习短文；朗读音色、风格与语速可调。

![短文阅读](docs/screenshots/passage.png)

句子分析提供句式、成分、语法、词组与发音讲解，支持进一步向 AI 老师提问。

![句子分析](docs/screenshots/sentence.png)

### 阅读与听力练习

同一篇短文可分别生成阅读和听力题组，支持填空、选择、判断和开放题，提供评分与建议。听力练习支持按句重听与慢速播放。

![听力练习](docs/screenshots/listening.png)

### 视频学习

导入本地视频与字幕，生成双语台词和场景切分方案。剪辑编辑器支持预览、调整片段范围与校正字幕时间。

![视频剪辑编辑器](docs/screenshots/editor.png)

场景片段支持逐句学习、跟读录音和听句拼写，结合画面、台词、译文与词汇进行练习。

![场景片段学习](docs/screenshots/clip-study.png)

### 学习计划与复习

将词汇本、短文与场景片段加入学习计划，设置每日学习量和学习顺序，自动安排每日任务与词汇的间隔复习。

![学习计划](docs/screenshots/plan.png)

词汇练习结合跟读、拼写与回忆，通过当轮小测检验学习情况。练习进度自动保存，可以接着练。

![词汇练习](docs/screenshots/practice.png)

### AI 老师

支持单词、用法和句子讲解，可结合学习资料与进度回答问题，也能按要求创建词汇本、短文、题组和学习计划。对话会保存，可以继续追问。

![AI 老师创建学习资料与计划](docs/screenshots/tutor-materials.png)

## 使用费用

**拼读软件完全开源免费**，采用 [MIT 许可证](./LICENSE)，不收取软件使用费或会员订阅费。

- **AI 大模型**：你自行选择服务商和模型，配置自己的服务密钥（API Key），并直接向服务商支付使用费用。
- **语音朗读**：使用你配置的语音合成服务，相关费用由该服务商按其规则收取。

实际成本取决于所选模型、语音服务和使用量，以服务商的定价与账单为准。拼读不代收这些费用，也不附带 AI 或语音服务额度。仅使用手动词汇管理、练习和统计时，无需配置这些服务。

## 安装

从 [Releases](https://github.com/abbish/pindu/releases) 下载对应系统的安装包：

| 系统 | 安装包 |
|---|---|
| macOS | `.dmg` |
| Windows | `-setup.exe` |
| Linux | AppImage、deb 或 rpm |

首次打开时，系统可能会要求确认，操作步骤见[安装说明](./INSTALL.md#1-下载安装包)。之后可以通过应用内更新安装新版本。

安装后在「设置」中配置以下服务：

- **AI 模型**：支持任意 OpenAI 兼容接口，内置 OpenRouter、MiniMax、月之暗面和 DeepSeek。
- **语音合成**：火山引擎豆包语音合成。

未配置时，手动管理词汇本、练习和统计功能仍可使用。

## 隐私

- 学习资料与记录（包括与 AI 老师的对话）保存在本机，不收集使用数据。
- 只有两种情况会联网：
  - 使用 AI 或语音功能时，相关内容直接发送给用户配置的服务商；
  - 检查更新时访问 GitHub，可以在设置中关闭。
- 服务密钥（API Key）未加密保存在本机，不会写入日志。

详见 [SECURITY.md](./SECURITY.md)。
