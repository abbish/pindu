# 拼读（Pindu.app）

[English](./README.en.md) · [安装](./INSTALL.md) · [安全与隐私](./SECURITY.md)

**把自己身边的英语素材，变成每天能学、能练、能复习的学习资源。**

学习中要读的英文资料、工作中要用的文档、生活里想看懂的视频，都可以成为你的英语学习起点。

拼读是一款桌面英语学习工具，帮助你把这些内容整理成词汇、短文与视频片段，配上阅读、听力、拼写和跟读练习，再通过学习计划与复习，每天接着学。

- **学习与你有关的英语**：从自己想看懂、听懂、用得上的内容开始，选择值得学习的词句。
- **把材料变成学习资源**：导入文本、文档或本地视频与字幕，补充译文、词汇资料和练习。
- **让学习持续下去**：把词汇、短文与视频片段加入计划，安排每日任务与词汇复习。

支持 macOS、Windows 和 Linux，无需注册账号。使用成本见[费用说明](#使用费用)，安装与服务配置见[安装说明](./INSTALL.md)。

## 功能

### 词汇本

从自己的材料中整理生词与词组，建立想学、需要用的词汇本。

- 收录单词与词组（短语动词、固定搭配、习语、固定短语），标注词组能否拆分使用。
- 添加方式：
  - 从文本、字幕或文档（txt、md、srt、vtt、docx、pdf）中提取生词与词组；
  - 手动录入，可一键 AI 补全；
  - 根据词汇本的场景描述生成补充词汇，可以先选择词汇需求建议。
- 词条资料包括音标、音节、自然拼读拆分、释义和由易到难的例句。
- 词汇本、短文与视频共用标签，侧边栏按标签汇总相关素材。

![词汇本](docs/screenshots/wordbook.png)

### 短文

把自己阅读的文章、课程资料或工作文档导入短文库，在原文中学词句。

- 导入英文材料时原文保持不变，仅补充译文、标题、难度与重点词。
- 阅读时：
  - 标出要学的词汇，点击可查看单词卡；
  - 支持逐句朗读与盲听；
  - 原文中选中的单词或词组可直接加入词汇；词汇可以移除，也可以按条件让 AI 重新挑选。
- 标题、难度和每句译文都可以直接修改。
- 句子分析：句式、成分、语法点、交际功能、值得学习的词组与发音要点。
- 阅读理解：
  - 选词填空、选择题、判断题自动判分；
  - 开放题提供评分与修改建议。
- 短文可以加入学习计划，按固定间隔安排。
- 需要更多练习材料时，可以基于词汇本、学习计划中的单词或主题描述生成短文，附逐句译文。

### 视频库

把想听懂的视频整理成适合反复学习的片段，结合台词练听力与跟读。

- 导入本地视频与对应字幕，整理字幕断句与翻译，并提供按场景切分的方案。
- 在剪辑编辑器中可以预览、调整入点与出点、校正字幕时间，确认后按方案精确切分。
- 每个片段提供三种学习方式：逐句台词学习、跟读录音、听句拼写；片段可以加入学习计划。
- 输入英文单词即可检索所有视频中出现过该词的片段。
- 视频处理无需另行安装软件。

### 学习计划与练习

将词汇本、短文与视频片段加入学习计划，让每天的学习有具体内容。

- 选择词汇本并设定每日新词数后，自动安排日程；计划可暂停，恢复后日程顺延。
- 新词采用三步练习：
  1. 完整信息；
  2. 隐藏英文，凭记忆拼写；
  3. 仅提供中文、音节与发音。
- 词汇复习按记忆等级安排，间隔为 1、3、7、14、30 天。答对升级，答错回到第一级；到期的复习自动加入当日任务。
- 短文与视频片段也可以加入计划，安排阅读或听力任务。

### AI 老师

遇到不理解的单词、用法或句子时，可以在学习过程中提问，并继续追问。

- 单词卡支持释义、拼写规律、同规律词、用法辨析、易混词与记忆方法等讲解。
- 讲解深度按学习者档案（小学生、中学生、成人）调整。
- 短文与视频中的句子也可以单独提问。

![AI 老师](docs/screenshots/tutor.png)

### 语音朗读

- 内置 15 个英文音色，单词与句子固定按英语朗读，数字和日期也按英语读出。
- 句子朗读风格可选：老师示范、自然口语、讲故事、新闻播报或自定义；语速、音调和音量均可调节。
- 相同内容再次朗读时可使用已有音频，减少重复生成。

## 使用费用

**拼读软件完全开源免费**，采用 [MIT 许可证](./LICENSE)，不收取软件使用费或会员订阅费。

- **AI 大模型**：你自行选择服务商和模型，配置自己的服务密钥（API Key），并直接向服务商支付使用费用。
- **语音朗读**：使用你配置的语音合成服务，相关费用由该服务商按其规则收取。

实际成本取决于所选模型、语音服务和使用量，以服务商的定价与账单为准。拼读不代收这些费用，也不附带 AI 或语音服务额度。仅使用手动词汇管理、练习和统计时，无需配置这些服务。

## 安装

从 [Releases](https://github.com/abbish/pindu/releases) 下载对应系统的安装包：

| 系统 | 安装包 |
|---|---|
| macOS | `.dmg` |
| Windows | `-setup.exe` |
| Linux | AppImage、deb 或 rpm |

首次打开时，系统可能会要求确认，操作步骤见[安装说明](./INSTALL.md#1-下载安装包)。之后可以通过应用内更新安装新版本。

安装后在「设置」中配置以下服务：

- **AI 模型**：支持任意 OpenAI 兼容接口，内置 OpenRouter、MiniMax、月之暗面和 DeepSeek。
- **语音合成**：火山引擎豆包语音合成。

未配置时，手动管理词汇本、练习和统计功能仍可使用。

## 隐私

- 学习资料与记录保存在本机，不收集使用数据。
- 只有两种情况会联网：
  - 使用 AI 或语音功能时，相关内容直接发送给用户配置的服务商；
  - 检查更新时访问 GitHub，可以在设置中关闭。
- 服务密钥（API Key）未加密保存在本机，不会写入日志。

详见 [SECURITY.md](./SECURITY.md)。
