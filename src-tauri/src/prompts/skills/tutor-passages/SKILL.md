# 短文与题组

## 写一篇新短文：你自己写

- 你掌握你们聊过的全部内容（学习者的水平、刚讲的语法点、想要的情节和语气、已经会的词），所以短文由你来写，结合这些上下文。
- 写之前想清楚：这篇是为哪些词或哪个语法点写的、给谁读（水平）、多长。一般 120–300 词；低年级更短、句子更简单。
- 要学的词要自然地出现，每个至少一次；不要为了塞词写出别扭的句子。
- 学习者想先看看时，先把正文发在回答里，等他满意再保存；学习者说直接存，就直接存。

## 保存：`mcp__pindu__save_passage`

- `text`：英文正文原样，一段一行；不要带中文、标题、题号。
- `vocabulary`：这篇要学的词或词组（原形）和这里的中文意思。程序会核对每个都出现在正文里（went 算 go，词组可以变形），没出现的会退回，按提示改正文或去掉这个词再存。
- `title`：英文标题，可以不写，程序会起。
- 学习者给的一段英文想留着学，也用它原样保存（这时 `vocabulary` 可以不填，程序挑重点词）。
- 翻译在后台做：保存后短文立即出现在对话里的卡片上，翻译好就能打开学。回答里说一句即可。

## 出题：`mcp__pindu__create_question_set`

- 先 `mcp__pindu__list_passages` 找到短文 id；刚存的短文翻译好后才会出现在列表里，还没出现时告诉学习者稍后再来出题。
- 阅读理解用 reading，听力用 listening；题量默认 3 道选择 + 2 道判断，学习者有要求就按要求。
- 出题在后台进行，做好后会通知你。

## 改短文与题组

- 先 `mcp__pindu__get_passage`：句子带序号，题组带 id。
- 标题、难度（a1 / a2 / b1 / b2）、场景：`mcp__pindu__update_passage`。
- 某句译文：`mcp__pindu__update_translation`（序号从 0 开始）。
- 词汇：`mcp__pindu__set_passage_vocabulary`（add 的词要出现在正文里；remove 去掉）。
- 题组：`mcp__pindu__get_question_set` 看题目和答案（可以和学习者一起讲题）；`rename_question_set` 改名。
- 删除短文、题组：`mcp__pindu__delete_passage` / `mcp__pindu__delete_question_set`，界面会请学习者确认；没结束的计划还在用的删不了。
- 练习成绩：`mcp__pindu__passage_results`。
