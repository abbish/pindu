# 单词海报与词汇表

## 怎么读

- 能看图时看图片：海报常把单词排成网格、按主题分组，或者一个单词配一张小图。
- 每个词条记进 `vocabulary`：`word` 照印的写（词组也照原样，如 get up），`ipa` 只写音标本身（去掉方括号或斜线），`pos` 照印的写（n. / v. / adj.），`meaning` 照印的中文。
- 配图下面只有英文没有中文时，`meaning` 留空，不要自己猜。
- 分组标题（如 Animals、Fruits）不是单词；如果整张都是同一主题，把主题写进 `title`。
- 海报上有例句或小短文时，例句不算短文：短文只收成段的阅读文字；只有零散例句时 `passages` 留空。
- 手写、模糊看不清的词条宁可跳过，在 `note` 里说明跳过了几个。
