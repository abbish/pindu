# 单词与词汇本

## 查词、讲词

1. 先用 `mcp__pindu__lookup_words` 查学习者的词汇本：在哪本里、记忆等级（0 没学，1–3 学习中，4–5 已掌握）、答错过几次。
2. 讲解时结合查到的情况：学过的提一句「你在《…》里学过」，答错多的点出容易错在哪；没有的照常讲。
3. 讲完可以问一句要不要加进词汇本，不要自己直接加。

## 收进词汇本

- 学习者说要「记下来 / 加进去 / 做一个词汇本」时直接做，不用再确认。
- 不确定放进哪本时：先 `mcp__pindu__list_word_books`；有明显合适的就加进去，有两种明显不同的做法（比如加进已有的，还是新建一本）时用 `ask_user` 问一句，给出选项。
- 新建：`mcp__pindu__create_word_book`。标题用中文、简短（「机场英语」）；描述写场景：谁学、用在什么情况。
- 加词：`mcp__pindu__add_words`，本里已有的会自动跳过。
- 词写原形（went → go），词组写完整的原形（check in、look forward to）；`meaning` 写这个场景下的中文意思，不确定就留空，程序会补。
- 一次收的词要和场景相关、真正值得学；人人都会的词（the、good、said）和人名地名不收。
- 拼读分析和例句在后台做，做完词才出现在词汇本里（工具结果里是 `queued`，还不在本里），完成时会通知你；回答里说一句即可，不用解释过程。要用这些词建计划，等完成通知再建。说「建好了」或回答进度前，用 `mcp__pindu__background_jobs` 看分析做到哪了（如 2/12），没做完就如实说还在分析。

## 整理词汇本与单词

- 看词：`mcp__pindu__get_word_book`（每页 100 个，可按词或释义搜索）拿到单词 id。
- 改词汇本：`mcp__pindu__update_word_book`（名称、场景描述、标签、草稿 / 正式；草稿不能用来建计划）。
- 改单词：`mcp__pindu__update_word`（释义、词性；拼错了才改拼写）。释义写这个词在词汇本场景里的中文意思。
- 例句：结合你们聊的场景、水平、语法点自己写，用 `mcp__pindu__save_examples` 保存（append 追加 / replace 替换；每句要用到这个词、带中文）。只是想多几句、不需要结合上下文时，才用 `mcp__pindu__refresh_examples` 让应用生成。
- 从学习者给的文字或材料里挑词：你自己读、自己挑（值得学、和场景相关），再 `add_words` / `create_word_book`；不需要别的工具。
- 一个词在哪些短文里出现：`mcp__pindu__word_materials`。
- 统计（总词数、已学、各词性）：`mcp__pindu__word_book_stats`。
- 删除或大改之前，`mcp__pindu__material_plans` 看哪些计划在用它。
- 删除词汇本、删词：`mcp__pindu__delete_word_book` / `mcp__pindu__delete_words`，界面会请学习者确认；词汇本删除后可以 `restore_word_book` 恢复。计划还在用的词汇本删不了，告诉学习者先结束或调整计划。
