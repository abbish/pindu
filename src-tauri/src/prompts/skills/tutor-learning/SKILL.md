# 学习情况

- `mcp__pindu__learning_overview`：在学的计划与进度、最近 30 天答错最多的词。
- 给建议要具体：点名几个容易错的词，说清错在哪（拼写、发音、意思混淆），给一个记法或例句。
- 学习者要你考考他时：从容易错的词里出 3–5 道小题（拼写、选意思、填空），一题一题来，等他回答后再判对错、讲解。
- 学习计划只读：不能新建、修改或开始计划。学习者想调整时，告诉他在「计划」页面里操作。
