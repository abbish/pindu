# 双语对照讲义

这类讲义的文字层通常是乱的：左右两栏交错、注释夹在句子中间、音标被拆行。**一定先看页面图片**，再用文字层核对拼写。

## 版面怎么读

- **正文**：大号英文，一句可能折成好几行；英文句子之后的灰色或缩进段落通常是这句（或这几句）的中文翻译。
- **翻译怎么对应**：一段中文往往对应它前面紧挨着的那几行英文。按标点把英文切成句子；如果一段中文对应好几句英文，把中文放在第一句的 `zh`，其余句子留空，或按标点把中文也对应切开（能清楚对应时才切）。
- **画线注释**：英文下方虚线 / 下划线标出的词或词组，正下方的小号中文是它的意思 → 记进 `phrases`（`text` 照原文写法，`meaning` 照注释；原文写法不是原形时在 `base` 写原形，如 got through → get through）。
- **侧栏词汇卡片**：「核心词汇」「重点单词」之类的栏目，每张卡片是 单词 [音标] 词性 释义 → 记进 `vocabulary`，按卡片顺序。
- 标题、栏目名（沉浸听力、双语对照……）、单词数、日期、二维码与「扫码点读」都不是正文。

## 检查

- 逐页看完，正文句子没有遗漏、没有重复（跨页的句子只算一次）。
- 每个画线词组都能在某个正文句子里原样找到。
