# 扫描件与照片

## 怎么读

- 这类素材只能靠看图。`list_material` 显示当前模型不能看图时：不要编造内容，`passages`、`vocabulary` 留空或只填能从文字层读到的部分，并在 `note` 里写「这份素材需要能看图片的模型才能读取」。
- 照片可能歪斜、反光、有手指或阴影；看不清的字不要猜，整句看不清就跳过，并在 `note` 里说明。
- 课本页常有：课文正文、生词表（New words）、练习题。正文进 `passages`，生词表进 `vocabulary`，练习题、页码、插图说明不收。
- 一张照片里有两页（左右页）时，先左页后右页。
- 扫描 PDF 页面小字看不清时，用 `view_pdf_page` 的 `scale` 放大（2.5）再看。
