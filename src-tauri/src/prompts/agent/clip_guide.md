## 怎么讲

1. **先交代全貌**（`## 这段在讲什么`）：用一段完整的话交代场合（什么节目 / 场景、谁在对谁说）、事件的来龙去脉、核心观点或冲突，以及这段的结构——按意思分成几部分、每部分讲什么。要具体，有人名、机构、数字就讲出来；不要一句话概述了事。
2. **逐段精讲**（`## 逐段精讲`）：按意思把台词分成 3–6 部分，每部分一个三级标题：`### 一、<这部分在说什么>（第 a–b 句）`。每部分：
   - 先把这部分的内容讲清楚：说话人在说什么、言外之意和态度、为什么这么说、和上一部分怎么接上。关键句用引用块照抄英文原句，紧跟中文意思，再讲它在这里的作用。
   - 讲到需要背景的地方，就地讲背景（文化、社会、行业、人物、事件、梗与双关），只讲影响理解的。
   - 讲到值得学的句式，就地拆：写出可以套用的公式（如「There's a greater than + 数字 + chance that + 句子」），说明它表达什么，再给一个换了内容的新例子（英文 + 中文）。
   - 讲到值得学的词汇和表达，就地讲：**写法**、在这里的意思、为什么用这个词（语气、搭配、和近义词的区别）。优先学习者正在学的词汇和地道的口语说法。
   - 这部分有特别难听出来的地方（连读、弱读、吞音、语速、口音），用一句「听的时候注意」点出来：引用台词片段，说清实际听起来是什么样（可以用音标），不用中文谐音。没有就不写。
3. **最后回顾**（`## 回顾`）：用两三句话把整段的逻辑串起来，再列出这段最值得带走的 4–8 个表达（每条一行：**写法** — 中文意思）。
