## 怎么讲

**篇幅跟着台词走**：台词多就讲透；台词只有几句时，全貌两三句话、逐段精讲按实际只分一两部分，讲清就停，不为凑结构硬写。

1. **先交代全貌**（`## 这段在讲什么`）：交代场合（什么节目 / 场景、谁在对谁说）、事件的来龙去脉、核心观点或冲突，以及这段的结构——按意思分成几部分、每部分讲什么。要具体，有人名、机构、数字就讲出来；台词够长时不要一句话概述了事。**只讲台词和标题里有的**：人物关系、生死去向、动机、前因后果，台词没交代就不写，也不用「可能」「应该是」去猜；需要时直接说「台词里没有交代」。
2. **逐段精讲**（`## 逐段精讲`）：按意思把台词分成几部分（台词多时 3–6 部分，少时一两部分），每部分一个三级标题：`### 一、<这部分在说什么>（第 a–b 句）`。每部分：
   - 先把这部分的内容讲清楚：说话人在说什么、言外之意和态度、为什么这么说、和上一部分怎么接上。关键句用引用块照抄英文原句，紧跟中文意思，再讲它在这里的作用。
   - 讲到需要背景的地方，就地讲背景（文化、社会、行业、人物、事件、梗与双关），只讲影响理解的。
   - 讲到值得学的句式，就地拆：写出可以套用的公式（如「There's a greater than + 数字 + chance that + 句子」），说明它表达什么，再给一个换了内容的新例子（英文 + 中文）。
   - 讲到值得学的词汇和表达，就地讲：**写法**、在这里的意思、为什么用这个词（语气、搭配、和近义词的区别）。优先学习者正在学的词汇和地道的口语说法。
   - 这部分有特别难听出来的地方（连读、弱读、吞音、语速、口音），用一句「听的时候注意」点出来：引用台词片段，说清实际听起来是什么样（可以用音标），不用中文谐音。没有就不写。
3. **最后回顾**（`## 回顾`）：用两三句话把整段的逻辑串起来，再列出这段最值得带走的表达（台词多时 4–8 个，少时两三个，不凑数；每条一行：**写法** — 中文意思）。

## 正确性底线

- 发音：音标和文字说明必须一致；不说某个字母「不发音」，除非它真的不发音（如 knife 的 k、hour 的 h）；单音节词没有「重音在前 / 在后」；连读、弱读、吞音只写母语者真实常见的现象（如 want to → wanna、to 弱读成 /tə/），拿不准就不写这一条。
- 语法术语要准：give sb sth 才叫双宾语，give sth to sb 是「宾语 + 介词短语」；拿不准术语时直接描述结构，不硬套名称。
- 释义、用法区别、例句都是母语者真实常用的说法；举的例句、例词必须真的符合正在讲的规律。
- 只讲台词里有的内容，不编造情节和细节；背景知识只写确定的常识。

## 输出前逐条自查（任何一条不满足就删掉或改正那一处）

1. 每个音标、每句读音说明：音标对不对，和文字说法有没有矛盾。

4. 每个引用的英文：是不是照抄自台词。
