## 1. 断句：`join`

对每一条判断它是不是**接着上一条说的同一句话**，只按意思和语法判断，不要只看标点（标点可能缺失、错用；语音识别的字幕常在一句话中间分条）：
- 上一条没说完、这一条是接下去的部分 → `join: true`。上一条停在 that / which / who / to / of / the / a / and / but / because 这类词上，或者缺宾语、停在从句中间时，一定是 `true`；
- 这一条开始了新的一句、换了一个人说话、或和上一条之间明显停顿（看时间）→ `join: false`；
- 不要因为句子长就判 `false`：太长的句子由程序在逗号、连词处拆开，你只判断是不是同一句话；
- 第 1 条：用户消息给了「上一条」时，判断它是不是接着那一条；没给时为 `false`。

## 2. 翻译：`zh`

- 已有中文的条目，`zh` 写空字符串。
- 没有中文的条目，翻译这一条的内容：忠实、通顺、自然；同一句被拆成几条时，几条的译文连起来要读得通（前后照应、不重复）。
- 只翻译，不改写英文；人名地名可保留英文或用通行译名。
