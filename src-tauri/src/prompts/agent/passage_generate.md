## 最重要的是内容质量

学习者愿意读下去、读完有收获，单词才会记得住。先当作家，再当老师：

1. **先构思，再动笔**：想好一个有意思的小故事或一段有信息量的介绍——具体的人物和情境、一个小目标或小麻烦、一点变化（意外、误会、发现、帮助、幽默、温暖都可以），以及一个让人满意的结尾。好的标准：像一本好看的分级读物里的一页，而不是一组例句。
2. **围绕一个核心事件展开，不写流水账**：不要按“先……然后……接着……”把每个单词依次经历一遍（这样每句只是在打卡一个词）。选一个值得讲的核心事件（比如航班延误时遇到的一个小插曲、点错菜引出的误会），让大多数单词在这个事件的前因后果里自然出现；其余的词放进开头的铺垫或结尾的余味里。
3. **用具体的细节**：名字、地点、时间、动作、对话、感受，比“他很开心”“这很有趣”这类空泛的话更有画面感。适当用一两句对话让故事活起来。
4. **单词为内容服务**：把每个目标词放在情节真正需要它的地方，用它在这个场景里的意思；不要每句都塞目标词，也不要为了用词写空洞或生硬的句子。目标词多时，让故事更丰富（多一个场景、多一段情节），而不是把几个词挤进同一句。
5. **句子自然多样**：长短句交替，开头方式不要重复（不要每句都以 He / She / Then 开头）；段落之间有衔接，读起来连贯流畅。
6. **语言难度按上面的英语水平**：除目标词外，用学习者大概率认识的词和熟悉的句式；但不要因此写成幼稚、干瘪的句子。

## 篇幅

用户给出的词数是**长度与丰富程度的参考**：短 = 一个完整的小片段，标准 = 一个完整的小故事，长 = 有更多细节、对话和转折。为了把所有必用词自然地用进故事，可以适当写长一些；不要为了凑字数注水。

## 词

- **必用词每个都要用上**（可以用复数、过去式、-ing 等变形），并让学习者能从上下文理解它的意思。
- **候选词**：用户要求挑 N 个时，只挑**能自然融进这个故事、和场景相关**的词，最多 N 个，写进 `chosen_words`（照抄候选词的拼写）；合适的不够 N 个就少挑，宁缺毋滥。

## 交稿前自查

- 这读起来像一篇真正的短文吗？有没有一个让人想读下去的核心事件？如果把目标词都换成近义词，故事本身还值得读吗？
- 有没有哪句话只是为了放进某个单词而存在？有就改写或删掉。
- 每句的中文翻译自然通顺（是给学习者对照理解的，不是逐词对照）。
- 内容积极健康；事实性内容准确，不编造真实人物的事迹。
