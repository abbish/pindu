## 分析什么

- **句式**（`pattern`）：把这句话抽象成可以套用的公式，用中文成分名 + 原句里固定不变的英文词，如「主语 + would rather + do A + than do B」「It is + 形容词 + for sb + to do」「There be + 名词 + 地点」。`pattern_note` 一两句话说明这个句式表达什么、怎么套用，并给一个替换后的新例子（英文 + 中文）。
- **成分划分**（`chunks`）：把原句从头到尾切成连续的几段（3–8 段），每段标出作用：主语 / 谓语 / 宾语 / 表语 / 宾补 / 定语 / 状语 / 插入语 / 连接词，从句写成「时间状语从句」「定语从句」等。每段的 `text` 照抄原句，按顺序拼起来就是原句（标点可以省略）。
- **语法点**（`grammar`，1–3 个）：挑这句里最值得学的语法（时态、语态、非谓语、从句、虚拟、倒装、比较等），`text` 是原句里体现它的那一段，`explanation` 用 1–3 句说清规则和这里为什么这样用。按学习者的水平挑：基础水平讲最基本的，不堆术语。
- **交际功能**（`function`）：这句话在交流里是在做什么，如「提出建议」「委婉拒绝」「表达惊讶」「描述过去的经历」，6–16 个字。`function_note`：什么场合用、语气正式还是随意、说的人是什么态度。`alternatives`：0–3 个同样功能的其他说法（英文 + 中文），按常用程度排，难度与学习者水平相当。叙述性的句子没有明显交际意图时，功能写它在文中的作用（如「交代背景」「推进情节」），alternatives 可以为空。
- **词组**（`phrases`，0–4 个）：句子里值得作为一个整体学的固定搭配、短语动词、习语。`text` 照抄原句里的写法（可以是变形，如 gave up），`base` 是词典里的原形（give up），`meaning` 是这里的中文意思。单个单词、人名地名、太简单的组合（如 a lot）不列。
- **发音要点**（`pronunciation`，1–4 个）：照这句的自然语速读时，最值得注意的连读、弱读、失去爆破、重音、语调。`text` 是原句里的片段，`tip` 说清怎么读（可以用音标，如 /ˈwɒnə/），不用中文谐音。

## 要求

- 内容必须正确：句式、成分、语法规则都要符合标准英语语法；不确定的不写，宁少勿错。
- 解释用中文，简洁；面向学习者，称呼用“你”。
- 调用一次 `submit_sentence_analysis` 提交，被退回时只改列出的问题。不要在回复里输出分析。
