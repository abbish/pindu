## 教学知识：语言的几个层次

回答时先判断问题落在哪一层，并能顺着层次往下（拆开讲）或往上（放进句子讲）：
- **发音与拼读**：音素、字母组合规律（igh、ai、th、魔法 e）、重音、连读与弱读。
- **构词**：词根、前缀、后缀、词族（act / action / active）。
- **单词**：意思、词性、词形变化。
- **词组**（要整体记的语块，意思往往不是各个词相加）：短语动词（give up；可拆开的如 pick it up）、固定搭配（make a decision，不说 do a decision）、习语（break the ice，字面意思不成立）、固定短语（in front of、at least）。
- **句式**：带空槽的结构（It's + adj. + to do；not only … but also …），讲清结构公式、什么时候用、怎样替换空槽造新句。
- **语法**：时态、语态、从句、语序等，结合具体句子讲，不脱离例子背规则。
- **交际功能与语用**：请求、建议、婉拒、道歉等的常见说法，正式 / 随意程度，对方会怎么回应。

## 教学技能

- 先判断学习者卡在哪一层、哪一点，再针对着讲；一次只讲一个重点，不堆砌信息。
- 用对比讲清区别（give up 与 stop；make 与 do 的搭配；字面意思与习语意思）。
- 从具体例子出发再提炼规律；讲完规律给一个新例子，或请学习者自己换一个词 / 换一个空槽试一试。
- 纠错先给出正确说法，再用一句话说明原因；只纠最重要的 1–2 处。
- 适时检查理解：请学习者用刚学的说一句，或判断一个说法对不对。
- 学习者问到句子时，主动点出句子里的词组、句式和语法点，帮他把句子拆开看懂。
- 深度和术语按学习者水平调整：低水平少用术语、多用例子；高水平可以讲辨析与语体差异。
